# Git & GitHub – Lernnachweis

## 1 · Git und GitHub verstehen

### 1. Was ist Git?
**Meine Antwort:** Git ist ein Werkzeug zur Versionskontrolle.

### 2. Was ist GitHub?
**Meine Antwort:** GitHub ist eine Plattform für Git-Projekte.

### 3. Was ist der wichtigste Unterschied zwischen Git und GitHub?
**Meine Antwort:** Git = Werkzeug, GitHub = Plattform.

### 4. Funktioniert Git auch ohne GitHub?
**Meine Antwort:** Ja.

### 5. Was ist ein Repository (Repo)?
**Meine Antwort:** Ein Ordner mit Dateien und deren Versionen

### 6. Was ist der `main`-Branch?
**Meine Antwort:** Der Haupt-Branch eines Projekts.

### 7. Was ist Markdown?
**Meine Antwort:** Eine einfache Auszeichnungssprache für formatierten Text.

### 8. Was bedeutet GitHub-Flavoured Markdown (GFM)?
**Meine Antwort:** Eine erweiterte Version von Markdown für GitHub

## 2 · GitHub-Flow

### 9. Bringe die Schritte in die richtige Reihenfolge
`Commit · Issue · Pull Request · Branch`

**Meine Antwort:** Issue Branch Commit Pull Request

### 10. Was ist ein Issue?
**Meine Antwort:** Eine Aufgabe, ein Fehler oder ein Verbesserungsvorschlag.

### 11. Was ist ein Branch?
**Meine Antwort:** Ein separater Arbeitszweig.

### 12. Warum arbeitet man für eine Änderung häufig auf einem eigenen Branch?
**Meine Antwort:** Damit Änderungen getrennt vom Haupt-Branch entwickelt werden können.

### 13. Was ist ein Commit?
**Meine Antwort:** Ein gespeicherter Änderungspunkt.

### 14. Wozu dient eine Commit-Nachricht?
**Meine Antwort:** Sie beschreibt, was geändert wurde.

### 15. Was ist ein Pull Request?
**Meine Antwort:** Ein Antrag, Änderungen in einen anderen Branch zu übernehmen.

### 16. Was bedeutet Review?
**Meine Antwort:** Andere prüfen die Änderungen.

### 17. Was bedeutet Merge?
**Meine Antwort:** Branches werden zusammengeführt.

### 18. Wann sollte ein Pull Request gemergt werden?
**Meine Antwort:** Wenn die Änderungen geprüft und bereit sind.

---

## 3 · Wichtige Git-Begriffe und Befehle

### 19. Was bedeutet Push?
**Meine Antwort:** Lokale Änderungen zu GitHub hochladen.

### 20. Was bedeutet Pull?
**Meine Antwort:** Änderungen von GitHub herunterladen.

### 21. Was ist der Unterschied zwischen Commit und Push?
**Meine Antwort:** Commit speichert lokal, Push lädt zu GitHub hoch.

### 22. Was ist der Unterschied zwischen Pull und Pull Request?
**Meine Antwort:** Pull lädt Änderungen herunter, Pull Request schlägt Änderungen zum Zusammenführen vor.

### 23. Was bedeutet Clone?
**Meine Antwort:** Ein Repository lokal kopieren.

### 24. Was macht `git status`?
**Meine Antwort:** Zeigt den aktuellen Status des Repositories.

### 25. Was macht `git add`?
**Meine Antwort:** Fügt Änderungen zur Staging Area hinzu.

### 26. Was ist die Staging Area?
**Meine Antwort:** Bereich für Änderungen, die committet werden sollen

### 27. Was macht `git log`?
**Meine Antwort:** Zeigt die bisherigen Commits.

### 28. Was bedeutet Branch wechseln?
**Meine Antwort:** Zu einem anderen Arbeitszweig wechseln.

### 29. Speichert `git add` bereits eine neue Version?
**Meine Antwort:** Nein.

### 30. Speichert `git push` deine noch nicht committeten Dateiänderungen?
**Meine Antwort:** Nein.

## 4 · GitHub-Flow praktisch erklären

### 31. Erkläre den GitHub-Flow in einem kurzen Satz.
**Meine Antwort:** Issue erstellen, Branch erstellen, Änderungen committen, Pull Request erstellen und anschließend mergen.

### 32. Ordne die Begriffe zu

| Bedeutung | Git-/GitHub-Begriff |
|---|---|
| Aufgabe | Issue |
| Arbeitszweig | Branch |
| Speicherpunkt | Commit |
| Änderungsantrag | Pull Request |
| Zusammenführen | Merge |

### 33. Welche Richtung beschreibt Push?
**Meine Antwort:** Lokal zu GitHub

### 34. Welche Richtung beschreibt Pull?
**Meine Antwort:** GitHub zu Lokal

### 35. Warum sind mehrere sinnvolle Commits oft besser als ein einziger riesiger Commit?
**Meine Antwort:** Sie machen Änderungen übersichtlicher und nachvollziehbarer.

### 36. Nenne ein Beispiel für eine gute Commit-Nachricht.

```text
README um Git-Befehle ergänzt
```

### 37. Warum ist die Commit-Nachricht `update` wenig hilfreich?
**Meine Antwort:** Weil nicht klar ist, was geändert wurde.
