##### Wichtige GitHub Funktionen und Begriffe: 
- **Repository:** Speicherort für Projekt mit Dateien und Versionskontrolle.
- **Branch:** Ein separater Zweig an dem man Änderungen machen kann, ohne den Hauptzweig direkt zu verändern.
- **Commit:** Änderungen abspeichern, auf Haupt -oder Nebenzweig
- **Issue:** Eine Aufgabe, Problem oder Verbesserungsvorschlag in einem Repository
- **Pull Request:** Änderung aus einer Branch in eine andere Branch übernehmen
- **Git Workflow:** Der Ablauf, wie man an einem Projekt arbeitet. Änderungen machen, speichern und Repository teilen.
